# Personal Budget & Expense Tracker

## Project Description

This is a Personal Budget & Expense Tracker website built using HTML and CSS.

The project allows users to enter expense information and view sample expenses in a table. It also includes a category dropdown, multimedia content, and a collapsible instructions section.

## Files

### index.html

The `index.html` file contains the structure of the Budget Tracker.

It includes:

- Main heading and description
- Add Expense form
- Expense name input
- Amount input
- Category dropdown
- Date input
- Add Expense button
- Expense table
- Sample expense data
- How to use section
- Budgeting video

### style.css

The `style.css` file controls the appearance of the website.

It includes:

- Page layout
- Colors and spacing
- Form styling
- Table borders
- Table header styling
- Alternating table rows
- Hover effects
- Focus effects
- Button styling
- Responsive design
